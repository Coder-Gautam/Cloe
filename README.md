# Cloé Caron — Propulsez votre Inc.

High-end, bespoke front-end website for **Cloé Caron (O2 Coaching)** built with modern HTML5, Vanilla CSS design tokens, and the GSAP 3 suite (ScrollTrigger + ScrollSmoother).

## Overview
- **Homepage Structure**:
  - Fixed Header & Responsive Navigation Drawer
  - Hero Banner with Depth Gradient Overlay & Callouts
  - Founder Intro Strip with Circular Avatar
  - 25-Year Partnership Marquee with Edge Fade Masks
  - 3-Column Problem Statement Grid
  - Le Modèle 5P Interactive Timeline & "Les deux autres méthodes" Book Cards
  - Founder Section (Credentials Table & Portrait Photo)
  - Team Testimonials (Comité de direction — One Team)
  - La Différence Dual-Tone Statement
  - Commencer — Growth Capacity Evaluation CTA
  - Editorial 3-Column Footer

## Tech Stack
- **Structure**: Semantic HTML5
- **Styling**: Modular Vanilla CSS with strict Figma design tokens
- **Animations**: GSAP 3, ScrollTrigger, ScrollSmoother, ScrollToPlugin
- **Typography**: Plus Jakarta Sans
